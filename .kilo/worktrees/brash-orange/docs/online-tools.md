# Онлайн-инструменты SUNBUR

Каталог: `/instrumenty`. Девять отдельных индексируемых страниц. На главной в секции `/#tools` есть прямые ссылки на каждую из них и на 3D-конструктор продухов:

| Адрес после `/instrumenty/` | Назначение |
| --- | --- |
| `burenie-pod-uglom` | Геометрия цилиндрического прохода: длина, смещение центра выхода и эллипс на поверхности |
| `skorost-vozduha-v-vozduhovode` | Средняя скорость в круглом / прямоугольном канале и равновеликий диаметр по заданной цели |
| `rashod-germetika` | Объём кольцевых швов, пользовательский запас и округление числа упаковок |
| `diametr-otverstiya` | Сравнение коронок по фактическому зазору, изоляции и гильзе; автоматический или ручной выбор, точные тарифы отдельно от справочника размеров |
| `uklon-kanalizacii` | Геометрический профиль по заданному уклону, перепад и глубина оси относительно единой отметки |
| `otverstie-pod-brizer` | Точный диаметр из справочника TION 4S / VAKIO KIV PRO либо из инструкции пользовательского прибора |
| `smeta-bureniya` | До 30 позиций по общим тарифам SUNBUR, с количеством и условиями для каждой |
| `kondensat-v-podpole` | Точка росы, сравнение с холодной поверхностью и парциального давления водяного пара внутри/снаружи |
| `zadanie-po-foto` | Локальная фотография, до 30 меток, размеры вручную, задание мастеру |

Каждый инструмент имеет SVG-схему или фото с метками, валидацию, сохранение/открытие JSON-проекта, печать/PDF и контекстного LLM-помощника. При изменении параметров предыдущий ответ скрывается, активный запрос отменяется. Сохранение также запоминает параметры в localStorage. Само фото не записывается в localStorage, но включается в скачиваемый файл проекта. В печать входят исходные значения, полная таблица позиций/меток и актуальный ответ AI.

## Подключение LLM

Создайте `.env.local` по `.env.local.example` и задайте `OPENAI_API_KEY`. Не коммитьте ключ. На хостинге используйте переменные окружения. Поддерживаются `OPENAI_BASE_URL` и `OPENAI_MODELS` (затем `OPENAI_MODEL`, по умолчанию `gpt-4o-mini`). Для разбора фотографии модель и совместимый gateway должны поддерживать изображения в Chat Completions. После изменения окружения перезапустите сервер.

`GET /api/tool-advice` сообщает только `{ configured: boolean }`. `POST /api/tool-advice` принимает `{ input, question, image? }`, где `input` — дискриминируемое поле `kind` и соответствующие параметры из `lib/home-tools.ts`. Результат всегда пересчитывается на сервере; передача клиентом доверенных сумм запрещена строгой схемой. Успешный ответ — `{ answer, source: "llm" }`. При отсутствии ключа возвращается 503, при сбое провайдера — 502. Шаблонные ответы под видом LLM не используются.

Пользователь отдельно разрешает прикрепление фото к вопросу. Без этой отметки передаются только параметры, заметки и координаты меток. Изображение на клиенте уменьшается до 1400 px по длинной стороне и конвертируется в JPEG; сервер принимает только встроенные JPEG-данные для инструмента `photo`, не скачивает произвольные URL. Файлы на сервере не сохраняются. Переданное фото обрабатывается настроенным LLM-провайдером по его условиям хранения данных.

Лимиты: тело 2,4 МБ, JPEG data URL до 2,2 млн символов, вопрос до 1200 символов, ответ до 1300 токенов, тайм-аут 22 секунды, без повторной генерации при сбое. На один процесс — 40 запросов в минуту, 6 на адрес и 3 одновременных генерации. На публичном хостинге дополнительно нужен общий лимит на доверенном прокси; пользовательский `x-forwarded-for` не должен обходить ограничение. Клиентские ошибки не раскрывают ответ провайдера или ключи.

## Границы расчётов и источники

- Наклонный проход: `L = t / cos(a)`, `s = t tan(a)`, большая ось `D / cos(a)`. Угол 0–75° от нормали стены, толщина 50–2000 мм, коронка 20–500 мм. Стена плоская с параллельными гранями; допустимость бурения и цена не определяются.
- Воздуховод: `v = Q / 3600 / A`, круг `A = πD²/4`, прямоугольник `A = WH`, диаметр по цели `sqrt(4Q / 3600 / v_target / π)`. Размеры переводятся из мм в м. При нулевом расходе скорость 0, целевой диаметр `null`. Целевая скорость пользовательская; потери давления, шум и нормы воздухообмена не рассчитываются.
- Герметик: `V_мл = π/4 × (D² − d²) × h / 1000`. Умножение на количество и `(1 + запас/100)`, упаковки округляются вверх. `h` — суммарная глубина всех швов, не вся толщина стены. Строго `D > d`; модель без расширения и подбора свойств материала.

- Подбор коронки геометрический. По умолчанию труба 110 мм, без изоляции и гильзы, минимальный зазор 1 мм на сторону → коронка 112 мм. Это пример тесного прохода, не универсальный монтажный допуск. Зазор 5 мм → 120 мм, 10 мм → 132 мм (фактически 11 мм на сторону). Проверяется самая широкая проходящая часть, включая раструб или фитинг.
- `lib/diameter-catalog.ts` содержит отдельный справочник коронок до 250 мм. Источники проверены 16.09.2026: [KEOS](https://keos.pro/catalog/osnastka/almaznye_koronki/koronki_dlya_ustanovok_i_almaznykh_dreley/), [Alteco Pro, включая 120 мм](https://alteco.kz/uploads/pdf/diamond-bits/bits-pro.pdf). Наличие у SUNBUR не предполагается. Цена берётся только при точном совпадении с `priceRates`; для 120/122/127 мм и других отсутствующих тарифов она `null`, без интерполяции или подстановки соседнего размера.
- `preferredDiameter: 0` означает автоматический выбор минимальной подходящей коронки. Ручной выбор допустим только при достаточном зазоре; недопустимый сохранённый выбор не даёт выбранного диаметра или цены. Изменение геометрии в интерфейсе возвращает автоподбор. Старые JSON-проекты без этого поля получают 0, сохраняя свой зазор. Гильзы и уплотнение выбираются по конкретной системе: [пример таблицы сочетаний трубы и отверстия Hauff](https://www.hauff-technik.de/fileadmin/user_upload/katalog_kabel_de_180711.pdf).
- Диаметр отверстия для оборудования не округляется вверх: отсутствие точной коронки требует согласования. Документация справочника проверена 16.09.2026: [TION](https://tion.ru/help/faqs/), [VAKIO KIV PRO](https://vakio.ru/wp-content/uploads/2021/10/re_kivpro.pdf). В справочнике нет автоматического подтверждения пригодности стены или места установки.
- Уклон канализации не подбирается по нормативам. По умолчанию 2 см/м — демонстрационный пример. Рельеф, гидравлика и промерзание не моделируются.
- Точка росы: приближение Магнуса `γ = ln(RH/100) + 17.62T/(243.12+T)`, `Td = 243.12γ/(17.62−γ)`. Ввод температур 0–50 °C, влажности 1–100%. Расчёт над жидкой водой; отрицательная вычисленная точка росы не является точкой инея. Для сравнения влагосодержания применяется парциальное давление `6.112 exp(17.62T/(243.12+T)) RH/100`. [Пояснение физического смысла точки росы, Vaisala](https://www.vaisala.com/en/expert-article/dew-point-temperature-what-does-it-mean-and-how-can-it-be-calculated). Нет автоматической команды открыть/закрыть продухи.
- Фотография не позволяет определить скрытую арматуру, материал, прочность и реальные размеры. Метки — проценты изображения, а не монтажные координаты. LLM составляет предварительное задание по введённым размерам и отдельно отмечает неизвестное.

## Проверки

```powershell
node --test tests/home-tools.test.mjs tests/tool-advice.test.mjs tests/vent-calculator.test.mjs tests/foundation-view.test.mjs
node node_modules/next/dist/bin/next build --webpack
node node_modules/typescript/bin/tsc --noEmit --pretty false --incremental false
```

Тесты API проходят через установленный AI SDK к локальному HTTP-провайдеру-фикстуре. Они проверяют транспорт, повторный серверный расчёт, изображения, валидацию и ошибки. Они не оценивают качество ответов настоящей LLM. После настройки ключа отдельно проверьте содержательные ответы всех инструментов и фото на выбранной модели.

Каталог связан с главной и навигацией сайта, новые URL входят в sitemap. Описание и инструкции рендерятся на сервере, у страниц есть canonical и JSON-LD WebApplication/BreadcrumbList. Публикация и поисковая индексация — отдельные шаги после принятия изменений.
